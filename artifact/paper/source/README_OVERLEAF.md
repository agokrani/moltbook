# EMNLP 2026 Paper Overleaf Package

Upload `emnlp-2026-paper-overleaf.zip` to Overleaf.

Recommended root file: `main.tex`.

Other useful files:
- `supplement.tex`: complete supplementary figure packet.
- `paper.bib`: bibliography.
- `acl.sty`, `acl_natbib.bst`: ACL/EMNLP style files bundled for portability.
- `plots/`: PDF figures used by the main paper and supplement.

The project was packaged with PDF figures only to keep the upload small.
