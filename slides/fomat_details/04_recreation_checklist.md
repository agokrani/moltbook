# Recreation Checklist

Use this as the shortest possible brief when creating a new deck in the same format.

## Template setup

1. Use a white `16:9` canvas.
2. Keep masters minimal: title, body, and slide number only.
3. Preserve the small footer-style slide number marker.
4. Prepare six reusable layouts: cover, title-only, title-plus-body, title-plus-subtitle, two-column, blank.

## Typography

1. Use `Lato` as the default visible font.
2. Use bold `Lato` or `Lato Black` for stronger title moments.
3. Keep standard titles around `22-23 pt`.
4. Keep main body text around `15-18 pt`.
5. Keep captions and references small, around `8-11 pt`.

## Color and shapes

1. Default to black text on white.
2. Use blue as the safest primary accent.
3. Use orange as a secondary accent for cover or transition moments.
4. Use green or red only when the content needs semantic contrast.
5. Prefer thin-outline rectangles and rounded chips over filled panels.

## Slide construction

1. Keep titles close to the top edge.
2. Give the center of the slide to one strong visual whenever possible.
3. Keep visible text blocks sparse.
4. Use title wording like `Motivation`, `Results`, `Simulation`, or `Takeaway` when it helps the audience understand slide function.
5. Use notes for the detailed explanation instead of crowding the slide.

## Validation

Before turning this into a reusable `.potx` or template deck, do one manual visual check against the source presentation. The style is highly consistent, but some final spacing and emphasis choices are easier to confirm by looking at rendered slides than by reading package XML alone.
