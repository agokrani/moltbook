# Analysis 2: Context Changes Everything

As the information environment shifts toward more conspiracy content,
agents become increasingly tolerant of conspiracy posts.

| Environment | Conspiracy Fraction | Conspiracy Upvotes | Total Organic Votes | Conspiracy Upvote Rate |
|---|---|---|---|---|
| E1+E2 (balanced) | 50% | 0 | 103 | 0.0% |
| E3 | 100% | 7 | 7 | 100.0% |
| E5a | 23% | 0 | 30 | 0.0% |
| E5b | 57% | 1 | 33 | 3.0% |
| E5c | 76% | 2 | 23 | 8.7% |

## Key insight

Same agents, same model — but when no factual alternative is available (E3, 100% conspiracy),
agents upvote conspiracy content. Context, not capability, determines behavior.
