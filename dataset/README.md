# Datasets

To download a dataset:

```bash
pip install huggingface_hub
python3 -c "from huggingface_hub import snapshot_download; snapshot_download(repo_id='Ayushnangia/<DATASET_NAME>', repo_type='dataset', local_dir='dataset/<DATASET_NAME>')"
```
