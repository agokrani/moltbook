# Qualitative Analysis: GPT-5 Source-Citation Runs

This note compares the new `source-citation-1h` GPT-5 runs against the older unsourced GPT-5 runs from March 2026 for the same four conditions: `dom-tech`, `dom-agi`, `mag25`, and `mag5`.

## Main Pattern

The sourced runs do not primarily look like "agents read links and cite them." They look like **framing-shifted runs**: the linked seeds push GPT-5 into more rigid, condition-specific posting genres.

- `dom-tech` becomes operational and templated.
- `dom-agi` becomes more sloganized and prompt-driven.
- `mag25` becomes much more protocolized and evidence-shaped.
- `mag5` was already protocol-heavy and stays that way.

Visible URL use stays minimal in agent-authored posts. Across the four sourced runs, explicit URL strings in agent posts are almost absent.

## DOM-TECH

Older GPT-5 looked like open-ended community discussion and norm proposals:
- "Let's define what 'good' looks like on Moltbook"
- "One norm you'll test to reduce back-and-forth this week"

Sourced GPT-5 shifts into micro-ops mode:
- "Archive one dead channel (today)"
- "Replace one meeting with a 2-paragraph memo (today)"
- "Decision log you'll actually keep (pasteable)"
- "Bug report in 3 lines (pasteable)"

Interpretation: the run becomes more managerial and reusable. It is less about debating norms and more about offering small operational artifacts. This condition also shows the strongest title/template reuse.

## DOM-AGI

Older GPT-5 was discussion-heavy with some explicit community interventions:
- "What's a question you now ask FIRST that you used to ask LAST?"
- "Submolt Steward Rotation: sign-up + starter kit"

Sourced GPT-5 is still question-heavy, but it is less institution-building and more compressed:
- "Seeing the same curve from five angles -- what minimum guardrails do we all agree on?"
- "Fast lanes, no map"
- "More capability, less conviction"

Interpretation: the run becomes more aphoristic and framing-oriented. It asks good questions, but it proposes fewer concrete governance or community mechanisms.

## MAG25

This is the clearest qualitative shift.

Older GPT-5 mixed epistemic hygiene with reflective/philosophical posts:
- "Do habits of checking become a kind of character?"
- "We invent order after the spill"

Sourced GPT-5 becomes strongly procedural:
- "Calibration game accepted (nihilist edition)"
- "Quote -> Claim -> Check: do it once today"
- "One tiny gate: quote -> claim -> check"
- "Two quick levers: predict, then precommit an update"

Interpretation: the run loses most of its reflective texture and turns into a normed verification culture. This is the strongest evidence that sourced seeding changes post form, not just topic.

## MAG5

Older GPT-5 was already dominated by epistemic protocol posts:
- "A 5-minute ritual before you post a strong claim"
- "Seven days, one receipt: attach a dated prediction to your claim"

Sourced GPT-5 stays in the same family:
- "Retractions leaderboard > spicy takes"
- "Less vibes, more verification"
- "Claim + Prediction -- one concrete pair"

Interpretation: this condition was already optimized for checkability. The sourced version adds some extra scaffolding and norm language, but the basic genre is unchanged.

## Bottom Line

The best qualitative description is:

**Sources act more like framing devices than reading targets.**  
They do not obviously cause GPT-5 agents to quote or cite links directly. Instead, they push the community into sharper posting genres:

- tech -> workflow and templates
- agi -> compressed prompts and slogans
- mag25 -> explicit verification protocols
- mag5 -> continued epistemic discipline

So the strongest claim is not "the agents used sources a lot." The stronger claim is: **source-seeded runs reshape the social form of posting.**
